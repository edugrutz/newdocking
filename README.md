# 🧬 DocKing

**DocKing** is an intuitive and efficient molecular docking tool built for researchers and professionals in biotechnology and pharmacology. With a user-friendly interface and powerful visualization features, DocKing streamlines the process of discovering and analyzing molecular interactions — accelerating scientific discoveries and drug development.


## 🚀 Features

- ⚛️ **Interactive Molecular Visualization** – Load and explore 3D structures of ligands and proteins.
- 🔍 **Docking Analysis Tools** – Analyze docking poses and binding affinities.
- 📂 **Multi-format Support** – Supports common molecular formats such as PDB, MOL2, and SDF.
- 🔧 **Offline Integration** – Built-in Open Babel and other dependencies bundled with the app (no installation required).
- 💡 **Simple and Clean UI** – Designed for productivity and ease of use.


## 🧠 Use Cases

- Academic research in **drug discovery** and **molecular modeling**.
- Teaching **molecular interaction concepts** in universities.
- Screening of **ligand-protein interactions** for biotechnological applications.


## 📦 Installation

### Pre-built Binaries

Download the latest release for your platform from the [Releases](https://github.com/edugrutz/DocKing/releases) page.

- **Linux**: `DocKing.AppImage`

No installation of external libraries (e.g., Open Babel) required — everything is bundled.

### From Source (Dev Mode)
```
git clone https://github.com/your-username/DocKing.git
cd DocKing
npm install
npm run dev
```
